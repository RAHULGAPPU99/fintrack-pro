# FinTrack Pro - All-in-One Business & Personal Finance App

An offline-first, mobile-friendly financial management web application combining **Cash Book, Income/Expense Tracker, Udhar Khata (Customer Ledger), Cash Denomination Counter, and PIN Security**.

## Features Included
- **4-Digit PIN Lock:** Secures financial records on startup (Default PIN: `1234`).
- **Live Dashboard:** Instant view of Net Cash Balance, Total Cash In/Out, and Udhar Receivables/Payables.
- **Cash Book & Expense Manager:** Track entries with categories, payment modes (Cash, UPI, Bank), and search filters.
- **Udhar Khata Ledger:** Party-wise credit/debit management with one-click WhatsApp payment reminders.
- **Cash Counter Calculator:** Tally Indian currency notes (`₹500` down to `₹1`) instantly.
- **CSV Export & JSON Backup:** Export reports for Excel/GST audits or restore full data anytime.

## Deployment & APK Build
1. Upload `index.html`, `style.css`, `app.js`, and `README.md` to a GitHub Repository.
2. Enable **GitHub Pages** in repository settings to run directly as a PWA on mobile browsers.
3. Wrap with **Capacitor** or **Cordova** to compile into a standalone Android `.apk`.
